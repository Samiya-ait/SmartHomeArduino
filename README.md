# SmartHomeArduino

## Description
This project is a smart home system created using Arduino and Tinkercad.

## Components Used
- Arduino Uno
- MQ-2 Gas Sensor
- PIR Motion Sensor
- LCD
- Relay Module
- LEDs

## Features
- Gas detection
- Motion detection
- Automatic lighting
- Temperature display
